## 🛠️ สิ่งที่ต้องเตรียม

```bash
# Node.js 18+
node --version

# npm หรือ yarn หรือ pnpm
npm --version

# ติดตั้ง dependencies
npm install
```

## 📋 Prerequisites

- JavaScript/TypeScript เบื้องต้น
- Node.js พื้นฐาน
- ความเข้าใจ HTTP/REST API (เล็กน้อย)

---

## 🎯 เป้าหมายหลักสูตร

1. เข้าใจ GraphQL อย่างลึกซึ้งตั้งแต่ต้น
2. สร้าง API ระดับ Production ได้
3. เข้าใจและป้องกัน Security Vulnerabilities
4. ออกแบบ Architecture ระดับ Enterprise
5. ทำงานกับ GraphQL ในระดับ World-Class ได้
